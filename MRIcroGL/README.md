# MRIcroGL assets

This folder contains selected NIfTI result overlays and PNG screenshots prepared for MRIcroGL visualization. They are presentation/result assets, not inputs to L1/L2/L3. Filenames summarize the displayed task/model/contrast; consult the originating FEAT analysis before quantitative reuse.

`mean_func.nii.gz` is a visualization underlay. The other NIfTI files are selected thresholded result maps, and `precuneus-pcc.png` is a rendered view.
